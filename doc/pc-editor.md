# PC エディタ

gui.exe の中で開く、**マウスとキーボードで触るためのエディタ**。パネルの絵とは別の窓に出る。
パラメータの層（[params.md](params.md) の作る順 5 番）の上に作った。

```
build/gui.exe <rom ディレクトリ> --editor     起動と同時に開く
```

窓では **F2** か、右クリックの品書きの「エディタを開く」で開く。閉じても隠すだけなので、
開き直すと同じところから出る。

## 面

| 場所 | 中身 |
|---|---|
| 左の一覧 | 32 パート。受信チャンネル、バンク MSB/LSB とプログラム、音量。行を選ぶとそのパートになる。幅はつまんで変えられる |
| ミキサー | 32 パート × Program・Volume・Pan・Dry・Reverb・Chorus・Variation |
| パート | 選んだパートのマルチパート 41 バイト全部。音色／音量と送り／受信と発音／フィルタと EG／ビブラート／モジュレーション／ピッチベンド |

上の帯に `XG リセット` と `オールノートオフ`。

## 触り方

| | |
|---|---|
| ドラッグ | 値を動かす |
| Ctrl+クリック | 数を打つ（打つのは生の値。Pan なら 0-127、Note Shift なら 40-88） |
| 右クリック | XG の既定の値へ |
| マウスを置いて待つ | 名前・キー（`part.volume` など）・既定の値 |
| Tab・矢印 | 部品の間を移る |

表示は名前（`L12`、`+3`、`POLY`、`B5` など）。受信チャンネルは `A1`-`A16`・`B1`-`B16`・`OFF`。

## 値の出どころ

**画面では覚えない。** パネルの面と同じ写し（`xg::model`）を読む。
選んでいるパートは 1 秒ごと、32 パート全部は 3 秒ごとに MU2000 へ一括ダンプを頼んで
読み返す（塊 1 つは 20ms ほど、1 つずつ頼むので 32 個で 1 秒弱）。まだ読めていない値は
`--` で出して、触らせない。

書いた直後の 0.5 秒は、行き違いで届いた古い返事で上書きしない（層の決まり）。
バンクを書くと今のプログラムも続けて送るので、すぐ効く。

## 中の作り

```
ui::pc_editor   面そのもの。ImGui だけに依存（窓も描画装置も知らない）
ui::pc_window   Win32 の窓と Direct3D 11。gui のタイマー（30 コマ／秒）から frame() を呼ぶ
```

問い合わせを実際に送るのは `panel::tick` の `model::poll`。エディタは `want_part` を積むだけ。
どちらも画面の糸で動くので、写しに錠は要らない。

字は Windows に入っている游ゴシック（無ければメイリオ、MS ゴシック）を読む。配らない。
DPI 対応はプロセス全体に効いてパネルの窓まで変わるので宣言していない
（高 DPI の画面では Windows が窓ごと拡大する）。

## まだ無いもの

* 音色名（ROM の中に 10 文字の名前の並びがある。バンクとプログラムからの目次を解けば、
  利用者の ROM から実行時に読める）
* エフェクトの全項目、ドラムのセットアップ、システム
* 保存と読み込み（塊のダンプをそのまま `.syx` にする）
* VST3 の画面に載せる
